# 恢复项目发现，移除脚本开发入口

2026-10-24 用户指出 0.1.13 的两个回退：把 package.json 命令当成普通项目的主要价值展示；默认移除 ~/Projects 发现导致旧项目消失。本轮按纠正直接修复，不新增 AI 任务执行功能。

根因除了默认范围缩水，还包括 README 被当成项目终止标记：explorations 是工作空间容器，阻断了下方 42 个旧项目。恢复当前工程、登记列表、~/Projects 的默认范围，使用有界广度优先目录发现；README 容器有子项目时不作为项目，Git/工程清单和已安装体系目录确定项目边界后不继续扫描源码。目录发现最多 15,000 目录、100,000 项、1,000 项目、深度 5、5 秒软预算，达到限制明确提示，部分结果保留已知目录；不以此宣称所有磁盘目录均已读取。

CLI 先提供当前项目，随后一次后台目录发现；前端一次请求补全列表，没有轮询或全项目正文索引。其它项目仍在选择时读取，现有正文缓存、分页与增量读取预算保持。移除“开发入口”、脚本计数、Git 按钮及前端自动 info 请求；旧只读 API 保留兼容。
