# 项目大盘

擎天大盘是本机只读的项目资料入口。它集中展示当前推进、下一步、关注事项，以及项目产物、Skills 和项目知识，并支持阅读原文和关联资料。

## 启动

接入或升级共享体系后，可以对 AI 说“帮我打开擎天大盘”。命令行方式为：

```sh
npm install -g @nextclaw/qingtian
qingtian dashboard
```

命令行工具要求 Node.js 22.12+。在当前项目运行时，默认优先进入当前项目；大盘默认绑定本机地址。

## 选择项目范围

登记额外项目：

```sh
qingtian projects add /path/to/project
```

指定扫描范围：

```sh
qingtian dashboard --root /path/to/projects
```

## 查看哪些内容

- 当前推进、下一步与关注事项：以项目明确记录的状态为依据。
- 项目产物：搜索、阅读任务相关 Markdown，沿关联文档追溯。
- 项目 Skills：查看项目范围内的入口、说明与附属文档。
- 项目知识：独立查看、搜索项目知识文档。

## 能力边界

大盘展示项目文档中的事实，不因文档存在或更新时间较新，就认定 AI 正在执行。它不替代宿主的实际调度，也不提供通用的编辑、安装或自动经营控制。
