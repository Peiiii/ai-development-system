# 项目大盘

擎天大盘是本机只读的项目资料入口。它集中展示当前推进、下一步、关注事项，以及项目产物、Skills 和项目知识，并支持阅读原文和关联资料。

## 启动

大盘无需向项目安装擎天规则。在任何项目目录执行：

```sh
npm install -g @nextclaw/qingtian
qingtian dashboard
```

命令行工具要求 Node.js 22.12+，在电脑上安装一次即可。支持 Git/worktree、常见工程清单和显式指定的普通目录。没有任务记录也能浏览 README、文档、已有 Skills 与协作规则，查看 package.json 声明的命令；存在明确工作记录才展示推进。已接入共享体系的项目也可以对 AI 说“帮我打开擎天大盘”。

## 选择项目范围

登记额外项目：

```sh
qingtian projects add /path/to/project
```

指定扫描范围：

```sh
qingtian dashboard --root /path/to/projects
```

## 查看哪些内容

- 当前推进、下一步与关注事项：以项目明确记录的状态为依据。
- 项目产物：搜索、阅读任务相关 Markdown，沿关联文档追溯。
- 项目 Skills：查看项目范围内的入口、说明与附属文档。
- 项目知识：独立查看、搜索项目知识文档。

- 开发入口：展示 package.json 脚本，了解运行方式，不自动执行。
- Git 活动：点击后只读当前分支、已跟踪文件变化与最近五次提交；不扫描未跟踪文件，不推断任务完成。

## 性能与读取范围

普通启动只识别当前工程和登记列表，不默认递归扫描整个 ~/Projects。其它项目资料在选择后读取；显式 `--root` 的发现有深度、目录项和项目数上限。资料由后端分页，默认每页 30 条、最多 40 条；搜索限定所选项目与资料模块。

正文缓存最多两个项目、合计 16 MiB；每项目正文预算 8 MiB、2,000 文件、12,000 目录项和 2 秒软扫描预算。刷新校验指纹，只重读变化的正文；新建与删除通过重新有限枚举发现。预算/错误导致不完整时显示提示，已有完整快照优先保留。文件系统阻塞不能被软时间预算硬中断。

总览只展示已读取缓存的资料，并明确覆盖项目数；总览中点击“待关注”至多读取前两个项目。未读取不等于零项，也不能把尚未检索的项目理解为没有匹配。普通模式没有递归 watcher、周期 Git 或后台全项目索引。

## 能力边界

大盘展示项目文档中的事实，不因文档存在或更新时间较新，就认定 AI 正在执行。它不替代宿主的实际调度，也不提供通用的编辑、安装或自动经营控制。
