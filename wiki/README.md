# 擎天 Wiki

擎天 是这套可复用体系的名称；AI Development System 是类别描述。本 Wiki 记录体系自身的结构、当前事实和演进状态。可复用的执行规则仍以 `payload/` 中对应的规则与 Skill 为准；Wiki 不复制它们的完整指令，也不代替目标项目维护自己的事实。

- [接入指南](getting-started.md)：通过现成 AI 编码助手安装、检查和升级擎天。
- [项目大盘](dashboard.md)：启动、选择项目范围、阅读推进与资料，以及只读展示的边界。
- [擎天愿景与定位](vision.md)：开篇完整展示一句话愿景，以及非专业用户无需学习和维护内部机制、体系自治理的补充；保留堪当重任、自主交付、普适易用、自我治理、持续进化五点及解释，展开可委托范围、易用与自治理、定位边界和发展依据。
- [使用 AI 做项目的问题树与擎天价值分析](developer-pain-points.md)：七组共 23 项问题，覆盖开发者与非专业用户的闭环委托，逐项记录具体表现、当前支撑与边界，并关联核心挑战，为价值讨论和案例验证提供基础。
- [当前阶段的核心挑战](core-challenges.md)：大型任务组织、并行冲突协调、流程可靠执行、跨时间持续推进、停滞后的策略调整；记录关键难点、候选探索方向和基于真实案例的验证方式。
- [三层架构与文件归属](system-architecture.md)：三类核心问题、完整原文树与口述；工作流层、方法层、知识与任务资料层，两种约束及工作流嵌套。
- [当前实现事实](current-state.md)：已经交付与尚未覆盖的能力。
- [工程产物与证据](artifact-traceability.md)：承载方案、执行状态与验证结果的核心支撑，以及设计、计划、验证、Review、日志和复盘的追踪链路与命名。
- [自动进化机制](evolution.md)：当前复盘驱动的沉淀回路与后续方向。

网页文档站位于 `https://ai-dev.nextclaw.io/docs/`，完整问题树、愿景、挑战与技术方法在文档站阅读；官网首页保留定位、用途、开始使用入口，以及架构图和流程切换的交互展示。原始 Markdown 只读入口随官网发布在 `https://ai-dev.nextclaw.io/wiki/README.md`。目标项目接入后，其产品、架构、环境和决策事实仍由目标项目自己的 Wiki 或权威文档维护。
