# 擎天 Wiki

擎天 是这套可复用体系的名称；AI Development System 是类别描述。本 Wiki 记录体系自身的结构、当前事实和演进状态。可复用的执行规则仍以 `payload/` 中对应的规则与 Skill 为准；Wiki 不复制它们的完整指令，也不代替目标项目维护自己的事实。

- [三部分结构与文件归属](system-architecture.md)：三类核心工程问题、Agent 工作流定位与介绍表达，流程约束、Skills、Wiki 的职责，以及工作流的层次与嵌套。
- [当前实现事实](current-state.md)：已经交付与尚未覆盖的能力。
- [工程产物与证据](artifact-traceability.md)：承载方案、执行状态与验证结果的核心支撑，以及设计、计划、验证、Review、日志和复盘的追踪链路与命名。
- [自动进化机制](evolution.md)：当前复盘驱动的沉淀回路与后续方向。

公开只读入口随官网发布在 `https://ai-dev.nextclaw.io/wiki/README.md`。目标项目接入后，其产品、架构、环境和决策事实仍由目标项目自己的 Wiki 或权威文档维护。
