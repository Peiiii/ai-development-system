# 体系背景：工作单位扩大、开发接续与验证闭环

2026-10-11 用户确认的背景论述。本文拥有体系的趋势判断、因果关系与介绍开场；架构与执行合同仍由原文档拥有。这是设计动机与方向判断，不是已证明的普遍效果或行业覆盖率结论。

## 核心判断

随着模型和 Harness 能力增强，Agent 能承担的工作单位有机会从局部修改扩大到完整需求、大型交付与持续迭代。**工作单位扩大是核心背景；跨执行者、跨会话和跨环境接续是由此产生的工程要求，验证闭环则让更完整的执行能力转化为可靠交付。**

## 因果结构

```text
模型能力与 Harness 能力增强
└── Agent 能承担的工作单位扩大
    ├── 从局部修改 → 完整需求 → 大型交付与持续迭代
    │
    ├── 推导一：工程工作需要脱离单个会话，支持接续与协同
    │   ├── 时间维度：任务更长，需要暂停、中断和恢复
    │   ├── 人员维度：多人接手、分工与协作
    │   ├── 会话维度：跨会话接续、多会话协同
    │   └── 环境维度：换设备、换地点、换执行环境
    │
    └── 推导二：完整工程闭环变得可行，也更值得建设
        ├── Agent 能推进更完整的工程过程
        ├── 验证提供反馈：结果与目标之间还差什么？
        ├── 未通过：定位缺口，返回对应环节继续修正
        └── 整体完成条件满足：退出循环、完成交付
```

## 接续与协同：工程状态独立于当前会话

工作单位扩大后，任务生命周期可能超出单个会话、一个人的工作时段和一个设备的使用周期。暂停与交接是正常使用需求，多人和多会话协同也需要共享有效依据。因此，项目资料须保存目标与约定、设计依据、执行状态、验证证据及下一动作，让接手者核对现场后从已有有效成果继续。

执行者和执行环境可切换是这一背景推导出的要求，不把“执行者变得可切换”本身当成独立的趋势前提。合上电脑、换地点或换设备的例子需要区分两类保障：资料与状态支持暂停后接续，执行本身持续运行则依赖宿主及实际运行环境。多人或多会话协同还需要处理并发修改、权限和状态归属；保存文档不自动完成这些能力。具体接续定义见[开发连续性](system-architecture.md#开发连续性可交接可接续)。

## 验证闭环：反馈与退出依据

Agent 有机会推进完整工程过程，因此建设从目标到交付的执行闭环更有价值。**验证是闭环的关键反馈机制，也是判断何时继续、何时退出的依据。** 它将实际行为与有效目标、验收标准对照，发现差距并将问题送回理解、设计、实现或验证等适用环节。

“验证通过”在整体交付层面指必要结果得到有效证据支持，并满足适用 Review、交付与复盘等完成条件，不是某个局部测试通过。存在真实阻塞时记录未完成项与所缺条件，不用盲目重试代替推进；阶段门、返工及整体完成仍沿现有 Lifecycle。证据角色见[工程产物与证据](artifact-traceability.md)，流程组织见[三层架构](system-architecture.md#总体模型三层架构)。

## 介绍开场

> 随着模型和 Harness 能力增强，我判断 Agent 能承担的工作单位会持续扩大，从局部修改走向完整需求、大型交付和持续迭代。
>
> 这会带来两个工程要求。首先，任务越来越长，中断、交接和协同会成为正常情况，所以开发状态需要脱离当前会话，支持跨人、跨会话和跨环境接续。其次，Agent 有机会推进完整工程过程，因此值得建立从目标到交付的执行闭环，其中验证负责发现差距、驱动修正，并提供退出循环的依据。
>
> 擎天就是围绕这两个要求组织的：让工程工作能够持续接续，也能够依据验证结果推进到完整交付。

## 已出现的信号与推断边界

OpenAI 的工程实践讨论了将人的职责转向环境设计、意图表达和反馈回路；Anthropic 的长任务研究讨论了跨会话开发与结构化产物交接。这些是一手实践信号，不据此宣称所有团队都已采用相同方式，也不宣称擎天是独有或普遍有效的方案。[OpenAI：Harness engineering](https://openai.com/index/harness-engineering/)、[Anthropic：Effective harnesses for long-running agents](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)

背景中的能力趋势与工程要求用于解释为何探索这套体系；已实现能力、实践证据和效果限制分别以[当前事实](current-state.md)、架构及具体测评为准。
