# Task Inbox

给一个小团队在本机记录待办的命令行工具。数据应在多次命令调用之间保留；不需要账号、云服务或第三方依赖。

既有入口为 `node bin/task-inbox.mjs`。为了让其它脚本可以使用它，命令的标准输出保持 JSON：

- `add <title>` 返回 `{ "id": 正整数, "title": 字符串, "done": false }`。
- `list` 返回按 id 升序排列的任务数组。
- `done <id>` 返回更新后的任务对象。
- `help` 返回可读的用法文本，不要求 JSON。

`TASK_INBOX_HOME` 指定数据目录；未指定时使用用户 home 下的 `.task-inbox`。无效输入应以非零退出码和 stderr 说明，不能破坏已存数据。数据文件损坏时应报告错误，不应悄悄清空。

已有代码只是一个尚未完成的起点。你可以调整内部结构，但请保留上述 CLI 合同。
